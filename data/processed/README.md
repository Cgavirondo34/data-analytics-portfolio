# Processed Data

This folder contains output files generated by the ETL pipeline (`02-python-automation/main.py`).

## Output files

| File | Description |
|---|---|
| `sales_report.csv` | Cleansed and enriched order-level data with derived columns |
| `kpi_summary.csv` | Aggregated KPI table grouped by year, month, and category |

These files are ready to be consumed by Power BI, Excel, or further analysis scripts.
